# БУ Маркет

Клиентская часть интернет-ресурса для размещения объявлений о продаже подержанных вещей.

**🌐 Демо:** [arsikbr06-creator.github.io/BUmarketKurs](https://arsikbr06-creator.github.io/BUmarketKurs/)

---

## О проекте

Курсовая работа по дисциплине **«Фронтенд-разработка»**.
Российский технологический университет МИРЭА.

Нормативный документ: Инструкция по организации и проведению курсового проектирования
СМКО МИРЭА 7.5.1/04.11.05-18.

Проект представляет собой одностраничное приложение (SPA) — клиентскую часть
маркетплейса, реализованную без использования фронтенд-фреймворков, на чистом
JavaScript ES6+ с применением методологии БЭМ, объектно-ориентированного
подхода и адаптивной вёрстки.

## Реализованный функционал

### Главная страница
- Hero-блок с призывом к действию
- Статистика площадки
- Сетка популярных категорий
- Свежие объявления с переходом в каталог

### Каталог объявлений
- Сетка карточек с фотографией, заголовком, ценой, категорией, городом и датой
- Поиск по заголовку и описанию (без учёта регистра, debounce 300 мс)
- Фильтрация по категории и диапазону цены (логика AND)
- Пагинация (20 объявлений на страницу)
- Сохранение и восстановление состояния фильтров при возврате со страницы объявления

### Детальная страница
- Полная информация об объявлении
- Конвертация цены в RUB / USD / EUR через внешний API
- Кэширование курсов в sessionStorage на время сессии
- Обработка ошибок (404 и сетевые) с возможностью повторной загрузки

### Форма создания объявления
- Валидация всех обязательных полей с граничными значениями
- Загрузка фотографии товара (file input + drag & drop, до 5 МБ)
- Автосохранение черновика в localStorage при каждом изменении
- Подсказки городов через Geo API (от 3 символов)

### Личный кабинет
- Список собственных объявлений из localStorage
- Статистика: количество объявлений, общая стоимость
- Удаление отдельного объявления и массовое удаление

### Адаптивная вёрстка
- Поддержка экранов от 320px до 1920px
- Брейкпоинты: 480 / 768 / 1024 / 1200 / 1440 px
- Гамбургер-меню на мобильных устройствах
- Все размеры в относительных единицах (rem, %, vw)

## Архитектура

Приложение построено на четырёх слоях:

```
┌──────────────────────────────────────────────────┐
│  Presentation Layer — UI-компоненты              │
│  Header, Footer, HomePage, Catalog, Listing_Card,│
│  Listing_Detail, Create_Form, Search_Bar,        │
│  Filter_Panel, Profile_Page                      │
├──────────────────────────────────────────────────┤
│  Routing Layer — клиентский SPA-роутер           │
│  Hash-based навигация для GitHub Pages           │
├──────────────────────────────────────────────────┤
│  Data / Service Layer — API_Client               │
│  Загрузка данных, кэширование, обработка ошибок  │
├──────────────────────────────────────────────────┤
│  Storage Layer                                    │
│  localStorage (объявления, черновики, фильтры)   │
│  sessionStorage (кэш курсов валют)               │
└──────────────────────────────────────────────────┘
```

Каждый UI-компонент реализован как отдельный JavaScript-класс с контрактом
из трёх методов: `render()` создаёт DOM-узел, `init()` навешивает обработчики
событий, `destroy()` очищает обработчики и DOM при размонтировании.

Все CSS-классы соответствуют методологии БЭМ:
`блок`, `блок__элемент`, `блок__элемент--модификатор`.

## Локальный запуск

Требования: Node.js 18+ и npm.

```bash
git clone https://github.com/arsikbr06-creator/BUmarketKurs.git
cd BUmarketKurs
npm install
npm run dev
```

После запуска приложение откроется по адресу `http://localhost:5173/`.

### Доступные команды

| Команда | Назначение |
|---------|-----------|
| `npm run dev` | Dev-сервер с hot-reload |
| `npm run build` | Production-сборка в папку `dist/` |
| `npm run preview` | Предпросмотр production-сборки |
| `npm run lint` | Статический анализ ESLint |
| `npm run format` | Автоформатирование Prettier |
| `npm run deploy` | Публикация на GitHub Pages |
